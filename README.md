## 🌐 About

**ROAMI** is a concept e-commerce website for selling curated PDF travel guides focused on Taiwan. Designed with a bilingual interface in English and Traditional Chinese (繁體中文), with all prices in New Taiwan Dollar (NTD / 新台幣).

> ⚠️ This is a university project for educational purposes only. No real payments are processed.
> 本網站僅供大學專題教育用途，不涉及任何實際交易。

## 🚀 Getting Started

No build tools or dependencies required. This is a pure HTML/CSS/JS single-file website.

### Run locally

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/roami.git

# Open in browser — just double-click the file
open index.html
```

### Deploy to GitHub Pages (free hosting)

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Click **Save**
5. Your site will be live at:

```
https://YOUR_USERNAME.github.io/roami
```
